# Interaction Study 2 · Flip · Curious

A blank sheet lies face down. Turning it over reveals the overdue statement.

- **Source artifact:** https://claude.ai/artifact/U48WUhDSUMmWekpdJ2Z49W
- **Live page:** https://klitsner.github.io/IXD-107-sequential-interaction-prototype/interaction-study-2-flip/

## How to interact
- Hover near any edge: a glove grips that edge and tugs it, and chevrons show which way to drag.
- Drag across the sheet: turn it over around its middle.
- ↺ (top right) resets the study.

## Files
- `index.html` — the complete artifact, copied unchanged from the published version. All CSS, JavaScript and SVG assets are inline.

## Setup and dependencies
None. There are no external libraries, fonts, images or network requests.

- **Run locally:** open `index.html` in a modern desktop browser (Chrome, Edge, Firefox, Safari). Or serve the folder, for example `python3 -m http.server`, and visit `http://localhost:8000/interaction-study-2-flip/`.
- **Input:** mouse or pen only. Touch input is ignored by design.
- **Sound:** uses the Web Audio API. Audio starts after your first click on the page.
